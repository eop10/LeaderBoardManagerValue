# Оценка наставников

Интерфейс для оценки наставников проектной деятельности ТПУ по месяцам учебного года. Работает в браузере, без сервера и сборки.

**Демо:** https://eop10.github.io/LeaderBoardManagerValue/

## Возможности

- **Месяцы.** Оценка проставляется и фиксируется каждый месяц учебного года, с сентября по август. Статусы месяца: не начат → идёт оценка → зафиксирован. Учебные годы создаются из меню года.
- **Критерии.** Настраиваются для каждого месяца: название, описание, максимум баллов, порядок. При открытии месяца подставляются из предыдущего; можно взять из любого прошлого месяца. После начала оценки критерии фиксируются.
- **Состав.** Наставники и команды для каждого месяца: добавить, убрать, перевести команду к другому наставнику. Новый месяц берёт состав из предыдущего.
- **Фильтры периода.** Учебный год и режим: месяц, сезон (осень сен–ноя, зима дек–фев, весна мар–май, лето июн–авг), весь учебный год или произвольный период «с — по». Для года и периода колонки можно показать по месяцам или по сезонам.
- **Оценка.** Ввод баллов в таблицу с проверкой диапазона, автосохранением и переходом по Enter. Прогресс заполнения. Комментарий к каждой команде.
- **Рейтинг наставника за месяц.** Среднее процентов по полностью оценённым командам.
- **Сводный рейтинг.** Для сезона, года или периода: рейтинг по каждому месяцу (или сезону) и итог — среднее месячных рейтингов.
- **Поиск и сортировка.** По наставнику или команде; порядок — как в составе или по рейтингу.
- **Экспорт CSV.** Таблица месяца или сводный рейтинг за период, открывается в Excel.
- **Сохранение.** Данные хранятся в `localStorage` браузера и сохраняются после перезагрузки.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Шрифты и иконки загружаются с Google Fonts, для них нужен интернет.

## Ограничения

- Данные хранятся только в браузере пользователя. Общей базы нет, у каждого браузера своя копия.
- Чтобы вернуть демо-данные, удалите ключ `mentor-eval-v3` в `localStorage`.
- Формулы рейтинга временные и ждут согласования с заказчиком.
