# Оценка наставников

Интерфейс для оценки наставников проектной деятельности ТПУ по сезонам. Один файл `index.html`: разметка, стили и скрипт внутри, без сборки, фреймворков и внешних библиотек. Данные лежат в JS-объекте и дублируются в `localStorage`.

## Возможности

- **Сезоны.** Черновик → оценка идёт → закрыт, без возврата назад. Создание сезона, переименование и удаление черновика (удаление только с подтверждением). Закрытый сезон доступен только для чтения.
- **Критерии.** Конструктор в черновике: название, описание, максимум баллов (по умолчанию 5), порядок стрелками. Копирование критериев из прошлого сезона. После старта оценки критерии и состав фиксируются.
- **Состав.** Наставники и команды: добавить, убрать, перевести команду к другому наставнику. Проверка дублей без учёта регистра. Новый сезон берёт состав из последнего.
- **Оценка.** Таблица с объединёнными ячейками наставников, проверкой диапазона `0…max`, автосохранением и переходом по Enter вниз и Tab вправо. Прогресс заполнения, индикатор сохранения, одна демонстрационная ошибка сохранения с повтором.
- **Рейтинг наставника.** Средний процент по полностью оценённым командам, с подписью «по N из M команд».
- **Завершение сезона.** Модалка подсчитывает незаполненные ячейки и переводит сезон в закрытый.
- **Сохранение.** `localStorage`, все обращения обёрнуты в `try/catch`: без хранилища страница работает в памяти.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Всё приложение: разметка, стили, скрипт |

## Запуск

Откройте `index.html` в браузере. Шрифты Manrope и Hanken Grotesk подгружаются с Google Fonts, для них нужен интернет; без сети используется `system-ui`.

## Ограничения

- Данные хранятся только в браузере пользователя, общей базы нет.
- Чтобы вернуть демо-данные, удалите ключ `mentor-eval-v2` в `localStorage`.
- Формулы рейтинга временные и ждут согласования с заказчиком.
- Нет поиска, сортировки, экспорта CSV, комментариев к командам и сводной вкладки «Все сезоны».
- Интерфейс рассчитан на десктоп от 1024 px.
