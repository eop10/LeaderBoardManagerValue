# Оценка наставников

Интерфейс для оценки наставников проектной деятельности ТПУ по сезонам. Работает в браузере, без сервера и сборки.

**Демо:** https://eop10.github.io/LeaderBoardManagerValue/

## Возможности

- **Сезоны.** Создание, переименование, удаление черновика. Статусы: черновик → оценка идёт → закрыт.
- **Критерии.** Настройка в черновике: название, описание, максимум баллов, порядок. Можно скопировать критерии из прошлого сезона. После начала оценки критерии фиксируются.
- **Состав.** Наставники и команды для каждого сезона: добавить, убрать, перевести команду к другому наставнику. Новый сезон берёт состав из последнего.
- **Оценка.** Ввод баллов в таблицу с проверкой диапазона, автосохранением и переходом по Enter. Прогресс заполнения. Комментарий к каждой команде.
- **Рейтинг наставника.** Среднее процентов по полностью оценённым командам.
- **Сводный рейтинг.** Вкладка «Все сезоны»: рейтинг наставников по каждому сезону и общий итог.
- **Поиск и сортировка.** По наставнику или команде; порядок — как в составе или по рейтингу.
- **Экспорт CSV.** Таблица сезона или сводный рейтинг, открывается в Excel.
- **Сохранение.** Данные хранятся в `localStorage` браузера и сохраняются после перезагрузки.

## Структура

| Файл | Назначение |
| --- | --- |

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Шрифты и иконки загружаются с Google Fonts, для них нужен интернет.

## Ограничения

- Данные хранятся только в браузере пользователя. Общей базы нет, у каждого браузера своя копия.
- Чтобы вернуть демо-данные, удалите ключ `mentor-eval-v2` в `localStorage`.
- Формулы рейтинга временные и ждут согласования с заказчиком.
