# Оценка наставников

Интерфейс для оценки наставников проектной деятельности ТПУ по месяцам. Работает в браузере, без сервера и сборки.

**Демо:** https://eop10.github.io/LeaderBoardManagerValue/

## Возможности

- **Сезоны.** Учебный год делится на два сезона проектной деятельности: осенний (сентябрь – февраль) и весенний (март – август). В шапке один выпадающий список сезонов (например, «Осень 2026», «Весна 2027»), внизу — «Сводка сезона» и 6 месяцев сезона.
- **Составы с витрины проектов.** Пары «наставник + команда» приходят с витрины каждый месяц, в интерфейсе они только для чтения.
- **Окно оценки.** Месяц M можно оценивать с 1-го числа M до конца месяца M + 1. В 00:00 1-го числа M + 2 оценки фиксируются автоматически. Если оценку месяца не начали, он закрывается с пометкой «Оценка за этот месяц не проводилась».
- **Критерии.** Настраиваются для каждого месяца: название, описание, максимум баллов, порядок. Подставляются из предыдущего месяца; можно взять из любого прошлого месяца. После начала оценки не меняются.
- **Оценка.** Ввод баллов с проверкой диапазона, автосохранением и переходом по Enter. Прогресс заполнения. Комментарий к каждой команде.
- **Рейтинг наставника за месяц.** Среднее процентов по полностью оценённым командам.
- **Сводка сезона.** Рейтинг по каждому месяцу сезона и итог — среднее месячных рейтингов.
- **Поиск, сортировка, экспорт CSV** — для месяца и для сводки сезона.
- **Экскурсия «Как пользоваться».** Пошаговая подсказка для организатора на 13 шагов: от выбора сезона до сводного рейтинга. Кнопка в шапке страницы, плашка-приглашение при первом входе. Подробности в разделе «Экскурсия».
- **Демо-дата.** Панель в правом нижнем углу задаёт «сегодняшнюю» дату (только для демо), статусы месяцев пересчитываются сразу.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Приложение: разметка и логика |
| `support.js` | Рантайм, который отрисовывает `index.html` |
| `tour/tour.js` | Экскурсия: сценарий, расчёт выреза и положения подсказки, плашка-приглашение |
| `tour/tour.css` | Оформление затемнения, подсказки и плашки под стиль системы |

| `tests/` | Автотест экскурсии (Playwright), см. раздел «Экскурсия» |

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Шрифты и иконки загружаются с Google Fonts, для них нужен интернет.

## Экскурсия

**Как работает.** Кнопка «Как пользоваться» в шапке запускает тур. Тур сам выставляет демо-дату 1 декабря 2026 и переключает вкладки месяцев, чтобы показать нужные экраны. Цели шагов находятся по атрибутам `data-tour="..."`, которые добавлены в `index.html` (единственное изменение разметки): `season`, `months`, `criteria`, `start-eval`, `deadline`, `score-cell`, `mentor-rating`, `comment-btn`, `search-export`, `summary-tab`, `summary-head`. Если меняете разметку, сохраните эти атрибуты на нужных элементах.

**Реализация.** Тур не использует внешних библиотек: затемнение с вырезом (SVG-маска) и подсказка (`.lb-pop`) рисуются в `tour/tour.js`. Положение считается заново при каждом показе шага, при `resize`/`visualViewport`, при прокрутке и при изменении размеров цели:

- **Вырез** равен `getBoundingClientRect()` цели, пересечённому с окном и с видимой частью каждого предка с `overflow`, за вычетом липких (`position:sticky`) шапки таблицы и первого столбца, которые закрывают край контейнера. Вырез не заходит на боковое меню и нижнюю ленту месяцев. Цикл `requestAnimationFrame` держит его на цели, пока тур открыт, а узел заново ищется по `data-tour`, поэтому замена DOM рантаймом не ломает подсветку.
- **Прокрутка.** Перед шагом цель прокручивается во всех вложенных контейнерах (изнутри наружу) с учётом липких краёв, затем сдвигается так, чтобы рядом осталось место для подсказки. Шаг показывается, когда положение цели не меняется около 130 мс.
- **Подсказка.** Ширина `min(380px, ширина окна − 32px)`, отступ от краёв окна не меньше 12 px. Сторона выбирается по свободному месту: сначала предпочтительная (`side` в `STEPS`), потом остальные. Если целиком нигде не помещается, цель сдвигается прокруткой, а если и это не помогло, подсказка получает `max-height` и прокручивает текст внутри. Стрелка указывает на центр видимой части выреза. В окнах ниже 640 px по высоте подсказка становится панелью (до 720 px шириной) внизу или, если цель в нижней части окна (лента месяцев), вверху. Кнопки и крестик всегда видны, Tab ходит по кругу внутри подсказки, Esc закрывает, ← и → листают шаги.
- Плашка «Демо · сегодня…» во время тура скрыта.

**Приглашение.** При первом входе вверху страницы появляется плашка «Впервые в оценке наставников?».

- Любое действие (запуск тура, крестик) прячет плашку навсегда. Кнопка «Как пользоваться» в шапке остаётся всегда.
- Состояние хранится в `localStorage`, ключ `mentor-eval-tour`.
- Если в `tour/tour.js` повысить `TOUR_VERSION`, плашка вернётся с текстом «Мы обновили правила оценки». Текст для этого случая лежит в константе `WHATS_NEW`.
- Чтобы увидеть первый вход снова, откройте страницу с параметром `?resettour`.

**Как изменить шаги.** Шаги лежат в массиве `STEPS` в `tour/tour.js`: иконка, заголовок, текст, цель (`el`, функция, возвращающая элемент с `data-tour`), предпочтительная сторона подсказки (`side`), `inline: 'end'` (если цель шире контейнера, показать её правый край) и подготовка экрана перед шагом (`prep`).

**Автотест.** `tests/` содержит Playwright-тест: проходит тур вперёд и назад на размерах 1000×500, 1000×555, 1024×640, 1280×720, 1440×900, 1920×1080, меняет размер окна на шагах 8, 9, 12 и проверяет числами: вырез совпадает с видимой частью цели (допуск 2 px; ожидаемая часть считается независимо через `document.elementFromPoint`), вырез не заходит на меню и ленту, подсказка внутри окна и не перекрывает вырез, стрелка смотрит на вырез, цель не спрятана под липкой шапкой, кнопки доступны. Запуск описан в `tests/README.txt`. Результаты прогона: `tests/РЕЗУЛЬТАТЫ.md`.

## Ограничения

- Данные хранятся только в браузере пользователя (`localStorage`, ключ `mentor-eval-v4`). Данные v3 не переносятся.
- Чтобы вернуть демо-данные, удалите ключ `mentor-eval-v4` в `localStorage`.
- Составы витрины в демо заданы константой в коде.
- Экскурсия рассчитана на демо-данные и дату 1 декабря 2026. На пустой системе часть шагов не найдёт свои элементы (шаг без цели показывается по центру окна).
- Состояние экскурсии хранится только в браузере: на другом устройстве плашка появится снова.
- Формулы рейтинга временные и ждут согласования с заказчиком.
